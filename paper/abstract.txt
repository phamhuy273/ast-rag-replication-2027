Locating source code that evidences a technical requirement is a common need in software analysis. Syntax-aware chunking is motivated by its preservation of code structure, yet chunk boundaries are confounded with the context metadata prepended to each chunk. In this Early Research Achievements (ERA) paper, we cross two chunking strategies, node-level abstract syntax tree (AST)-first chunking with line fallback and 50-line windows, with and without a hierarchical context header. We evaluate them on 25 job descriptions, whose required skills serve as requirements, and 40 public repositories (872 chunks), using BM25, dense retrieval, and cross-encoder reranking against 882 human-labeled pairs. After reranking, headers improved NDCG@10 for AST chunks from 0.341 to 0.487 (Holm-adjusted p = 0.0001), and without headers, line windows outperformed AST chunks (0.580 vs. 0.341, p_Holm < 0.001). Line windows without headers significantly outperformed AST chunks with headers (Delta = -0.093, p_Holm = 0.0438). Line windows with headers scored highest (0.621), significantly above AST with headers in an exploratory comparison (Delta = -0.134, p = 0.0003). Following a parser upgrade, the AST-arm fallback rate was reduced to 0.0%, and an audit clarifies boundary effects, coverage differences, and a research roadmap for code retrieval.
