\section{Related Work}
\label{sec:related_work}

We organize related work into four domains:

\textbf{Code Chunking for RAG:} Line-based chunking can disrupt semantic boundaries~\cite{zhang2025cast}. \castname~\cite{zhang2025cast} addresses this by recursively partitioning AST nodes and merging siblings under size limits, reporting gains on RepoEval and SWE-bench. However, subsequent controlled experiments in code completion show that structure-aware chunking does not reliably outperform sliding windows~\cite{wu2026chunking}, and line-based slicing matches syntax-aware splitting across compute budgets~\cite{galimzyanov2025practical}. While those studies target code synthesis, we evaluate human-labeled requirement-to-code evidence retrieval and orthogonally control context headers.

\textbf{Dense Retrieval and Reranking:} Neural code search embeds natural-language queries and source code into shared representations~\cite{feng2020codebert,guo2022unixcoder,husain2019codesearchnet}. Modern dense models such as BGE-M3~\cite{chen2024bgem3} perform multilingual semantic matching. To overcome single-vector compression limits, two-stage pipelines integrate cross-encoder rerankers that jointly attend across query and chunk tokens~\cite{hu2023revisiting,costv2024apsec}. We adopt this recall-then-rerank architecture to investigate how chunk geometry and headers interact with cross-encoders.

\textbf{Context Enrichment:} Isolated code chunks frequently lack enclosing class and package context. Prior approaches enrich completion prompts with repository context iteratively (RepoCoder~\cite{zhang2023repocoder}) or benchmark cross-file dependencies (RepoBench~\cite{liu2024repobench}, CrossCodeEval~\cite{ding2023crosscodeeval}). We investigate a lightweight alternative: prepending standardized hierarchical context headers to individual chunks prior to retrieval.

\textbf{Requirements Traceability and Skill Mining:} Tracing natural-language requirements to source code has deep roots in software engineering~\cite{antoniol2002traceability,gao2024triad}. Separately, repository mining has been employed to classify developer expertise from framework usage~\cite{montandon2019identifying}. We adopt the traceability perspective: treating required technical skills as requirements and retrieving concrete code evidence, without assessing individual developers.
